# Fictional catalog-deletion snapshots

These two canonical backups contain one entirely invented book, not a personal
library. They were generated by the real repository API: preview/commit a catalog,
export `before`, call `deleteBook`, and export `after` from the same source library.
Both exports were validated by the canonical backup parser. Formatting alone was
compacted when copying them here.

The browser test imports both files through the normal backup picker and explicitly
accepts the second backup's deletion conflicts. It then previews an older catalog
whose source-row notes differ. Separate disposable contexts test keeping the
deletion and explicitly restoring the catalog entry. No database backdoor or
book-delete UI is used.
